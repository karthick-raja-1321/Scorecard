# EduArena Live

EduArena Live is a browser-only classroom gamification dashboard built with HTML5, CSS3, and Vanilla JavaScript.

## Features

- Teacher control center for participant and session management
- Real-time leaderboard with rank animation and scoring controls
- Top 5 podium tiers with celebration effects
- Live activity feed and real-time statistics dashboard
- Dynamic achievement badges
- Accurate stopwatch with session states
- CSV and JSON export
- Theme and sound preference persistence via localStorage
- Fullscreen presentation mode
- Responsive design across desktop, tablet, mobile, and projector views

## Stack

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
- Font Awesome CDN

## Run

Open `/index.html` in a browser or deploy as static files to GitHub Pages.
